# wcat implementation plan

Design approved by the owner on 2026-09-05. Branch: `feat/wcat`.
Production promotion still requires separate approval.

## Implementation

1. Write failing tests against the real physics and behavior exports. Cover
   gravity, all bounds, platform crossings and disappearing support, rolling
   friction, rest, throw sampling, deterministic idle timers, following,
   reachable jumps, naps, mobile restrictions, and reduced motion.
2. Implement pure `src/wcat/physics.ts` and `brain.ts`. Coordinates use the
   horizontal center and bottom of the body. Time uses seconds. Keep one
   definition of body sizes, gravity, restitution, and rest thresholds.
3. Write failing component tests for lifting, release, touch cancellation,
   mobile platform exclusion, reduced motion, and cleanup. Implement
   `Wcat.tsx` with one animation loop and ref-based positions. Read window
   rectangles before writing transforms. Exclude hidden and exiting windows.
   Cancel gestures on pointer cancellation, lost capture, blur, and unmount.
4. Mount on both Desktop branches. Draw the 44 px CSS cat and 36 px ball.
   Preserve the documented white eyes and mouth. Add keyboard lifting,
   positioning, and dropping, plus English and Spanish instructions.
5. Extend the existing browser gate for cat-to-ball-to-cat interaction and
   mobile floor placement. Check actual touch scrolling and long-press
   dragging in a browser. Verify moving/closing a supporting window.
6. Run all tests with one worker, build, and lint. Record pre-existing lint
   failures separately. Run the browser gate against a local built preview
   and a Cloudflare version preview. Inspect desktop and phone screenshots.
   Measure frame work with ten windows visible. No production deploy.
7. Update the hand-off with actual results and remaining art limitations,
   commit the branch, and present the preview for review.

The hand-off refers to a writing-plans skill that is not installed in the
available skill directories. This plan follows the repository's existing
plan structure directly. No new runtime dependency is needed.

## Verification record

- Initial baseline: 104 tests passed. Lint had 19 errors and one warning in
  `src/i18n/index.tsx` and `src/reactbits/`. Those remain unchanged.
- New tests first failed because the physics, brain, and component modules
  did not exist. The completed suite passes 139 tests across 16 files.
- Disabled restitution temporarily. Three boundary tests failed on zero
  reflection, then the change was restored. The ceiling assertion was also
  strengthened to check bounce speed rather than just gravity's direction.
- Build passes. Main JS: 599.91 KB, 192.67 KB gzip. CSS: 35.22 KB.
  Existing large-chunk and outdated Browserslist notices remain.
- ESLint passes for every changed TypeScript file. Full lint still fails
  on the same baseline errors. This repo has no `type-check` or `check:any`
  scripts; `npm run build` runs `tsc -b`. No `any` was added.
- Local built preview: 33/33 browser gate checks passed, including actual
  Chromium touch events for swipe scrolling and long-press dragging.
- Focused browser checks observed an autonomous window jump and a fall
  when the supporting window was dragged. Desktop and mobile screenshots
  were inspected. No physical phone testing has been performed.
- Ten-window callback profile: mean 0.31 ms, p95 0.60 ms, max 0.70 ms across
  67 frames in five seconds. These are callback times, not total frame time.
- Browser-discovered corrections: palette clearance above the cat; a
  clipped container for remote cursors; no native text selection on mouse
  lift; the gate watches rest before taking its next screenshot.
- Floor jumps can reach ordinary-height windows. Inter-window jumps keep
  the original 180 px limit. A slow-frame test verifies settling at 10 FPS.
- Cloudflare preview verification will be recorded after upload. The site
  repository has no GitHub Actions workflows, confirmed through the API.
