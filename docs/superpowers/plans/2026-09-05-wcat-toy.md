# Sticker removal, flat tail and yarn play

Owner-requested additions to `feat/wcat`, preview only.

1. Right-click a placed sticker to remove only that instance from the shared
   room. Keep the palette unchanged and ignore secondary-button drags.
2. Attach the vector tail behind a foreground body shape at a fixed rear hip.
   Keep a constant stroke, a stationary base and flat outer-curve swishes.
3. Treat the live desktop selection rectangle as a temporary solid obstacle,
   including its top as a perch. Resolve overlaps when the rectangle grows or
   moves. Removing it must remove support immediately.
4. Add a private yarn-ball control to the palette. Its position, throws,
   collisions and trailing string stay in this browser. Drag/throw, keyboard
   controls, touch scrolling/hold, right-click removal and reduced motion.
5. Let the cat chase and pounce on a thrown yarn ball, bat it away, then lose
   interest after a bounded play session. Give it a cooldown; do not keep
   extending interest whenever the ball moves. Direct interaction wins.
6. Exercise real modules with failing tests before changes. Run full tests,
   build, changed-file lint and browser checks in isolated rooms, inspect the
   new visuals, upload a version preview and update the existing PR.

The yarn emoji is interpreted as 🧶. It is a local toy, not a new shared
sticker kind. No dependencies or production deployment are authorized.

## Verification

Implemented. All 209 tests pass with a single worker; the production build
passes. Changed TypeScript files lint cleanly. Full lint retains 19 existing
errors and one warning in unrelated i18n/reactbits files.

Watched the sticker removal, secondary-button drag, rear-tail geometry,
selection collisions and close-wall jump tests fail before the corresponding
fixes. The jump initially stopped against the solid side; it now clears the
wall before crossing onto the top. The yarn hold test also caught an early
cooldown that would have interrupted the first throw, and now passes.

The new local toy browser gate passes 20 checks. It uses actual pointer and
keyboard inputs, a controlled clock and seeded randomness, not private model
state. The initial throw harness paused longer than the 80 ms velocity window;
adding an intermediate pointer sample made it exercise a real throw. The
first selection-perch browser run reproduced the wall-jump regression.
New screenshots were inspected for the tail, yarn/string and selection perch.

Preview upload and the complete hosted browser regression run are pending.
